# 拾书 Bookrest 测试方案

**版本**：v0.1.0（文档 r0）
**日期**：2026-09-29
**状态**：待评审（r0）
**上游文档**：`260929-拾书-PRD-v0.1.0.md`（FR-x.y、§6 验收指标）、`260929-拾书-详细设计-v0.1.0.md`、`260929-拾书-任务拆解-v0.1.0.md`

**硬约束**：全部测试数据的磁盘写入总量 **≤ 1GB**（生成器内置硬上限，超限即失败）。

---

## 1. 测试策略

| 层级 | 规模 | 数据量 | 频率 | 目的 |
|---|---|---|---|---|
| 单元 | 0–50 | < 1MB | 每次提交 | 纯逻辑：指纹、合并、剪枝、体检规则、存储原子性 |
| 集成（L1） | 300 本 | ~8MB | 每次提交 | 扫描 → 索引 → 缩略图 → 查询 → 同步全链路 |
| 性能回归（L2） | 2,000 本 | ~50MB | 每周 / 每里程碑 | 单本成本、内存、启动（外推 2 万本） |
| 发版验收（L3） | 20,000 本 | ~360MB | 每个里程碑 1 次，手动 | PRD §6.2 全部指标 |
| 真实尺寸（L4） | 60 本 | ~180MB | 每里程碑 | 缩略图解码/编码成本代表性 |
| 边界（edge） | ~40 本 | < 5MB | 每次提交 | 异常文件、命名地狱、结构极端 |

原则：**可重复**（固定种子）、**幂等**（数据造一次复用，不重建）、**可自动断言**（不靠肉眼）、**盲区诚实标注**（§6）。

## 2. 测试数据生成器规格（`tools/testdata-gen`）

| 项 | 规格 |
|---|---|
| 语言 | Go（与产品同语言，无额外运行时依赖） |
| 用法 | `testdata-gen --scale l1|l2|l3|l4|edge --out <dir> [--seed 42] [--max-bytes 900MB]` |
| 幂等 | 目标目录存在 `manifest.json` 且种子/规模一致且抽样校验通过 → 直接复用，不重建 |
| **写入硬上限** | 累计写入字节 > `--max-bytes`（默认 900MB）→ 立即中止并返回非 0（对应 PRD 硬约束） |
| 记账 | `manifest.json` 记录：规模、种子、每本体积、总字节、文件清单、生成时间 |
| 内容 | CBZ = N 页小 JPEG + 可选 `ComicInfo.xml`；EPUB = mimetype + container + OPF（±元数据）+ 封面 |
| 分布 | 页数 1–300（按规模档位缩放）、系列/卷号按规则生成、目录层级 1–3 层（edge 档另有极端结构） |

### 2.1 规模档位与预算

| 档位 | 本数 | 单本均量 | 数据量 | 用途 |
|---|---|---|---|---|
| l1 | 300 | ~25KB | ~8MB | 每次提交集成 |
| l2 | 2,000 | ~25KB | ~50MB | 性能回归 |
| l3 | 20,000 | ~18KB | ~360MB | 发版前验收 |
| l4 | 60 | ~3MB | ~180MB | 真实尺寸缩略图成本 |
| edge | ~40 | 混合 | < 5MB | 边界专项 |
| **合计** | — | — | **≤ 600MB** | 满足 1GB 上限 |

缩略图缓存按懒生成处理：**验收脚本不批量生成缩略图**（否则 2 万本全量浏览最坏约 390MB），缩略图成本在 L4 档用 60 本真实尺寸单独测；缓存另有 `cache_max_bytes`（默认 512MB）LRU 上限兜底。

### 2.2 边界族清单

| 族 | 构造方式 | 验证点 | 关联 FR |
|---|---|---|---|
| 封面缺失 | zip 内无图片项 | 占位图 + 进体检，不崩 | FR-2.2 / FR-5.3 |
| 内嵌元数据有无 | ±`ComicInfo.xml`、EPUB ±OPF | 优先级与回退路径 | FR-4.1 / FR-4.3 |
| 系列断档 | 人为缺第 3、7 卷 | 缺卷报告命中 | FR-5.1 |
| 重复 | 精确重复 + 近似重复（同封面异页数） | 精确命中、近似不误报 | FR-5.2 |
| 损坏族 | 截断 zip、CRC 错、0 字节、伪装扩展名（.cbz 实为 txt） | 不崩、进体检、缩略图失败事件 | FR-5.3 |
| 命名地狱 | 中文/日文/emoji、>200 字符、`[]{}【】`、末尾空格与点 | 解析与展示正确、无路径错误 | FR-4.2 / FR-8.2 |
| 结构极端 | 深目录 12 层、单目录 5,000 本、空目录 | 扫描正确、性能可接受 | FR-1.3 |
| 页数极值 | 1 页 / 300 页 | 书脊宽度映射不越界 | FR-2.7 |
| 权限 | 只读目录、无权限目录 | 明确报错，不静默失败 | FR-1.6 |
| 越界链接 | 指向库外的符号链接 | 不跟随、不扫描 | 设计 §8 |

## 5. 缺陷分级

| 级别 | 定义 | 处理 |
|---|---|---|
| P0 阻断 | 写源文件、丢意图、崩溃、离线不可用 | 立即修，阻断发版与 tag |
| P1 严重 | 核心功能不可用、增量漏检超出已知盲区 | 发版前必修 |
| P2 一般 | 边缘格式、体验问题、性能不达标但可用 | 可延后并记录 |
| P3 轻微 | 文案、样式、日志措辞 | 记录，择期修 |

## 6. 已知测试盲区（诚实清单）

1. **网络存储真实延迟**：用注入延迟近似，不能完全替代真 SMB/NFS 行为差异。
2. **杀软/OS 首次访问开销**：只在本机 Windows 实测过，其他环境未覆盖。
3. **超大规模（>5 万本）**：未测，内存与启动指标的线性外推在此之上不保证。
4. **损坏文件族**：只覆盖常见几种，zip 结构损坏的变体无穷，无法穷举。
5. **系统 WebView 差异**：v1 仅 Windows，多平台渲染差异未覆盖（Wails 路线的固有风险）。
6. **断电一致性**：只测「强杀进程」，未测真实断电（无硬件手段）。
