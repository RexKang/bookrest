# 封面与在线信息补全 · 改造记录

**日期**：2026-09-30
**起因**：用户指出「书籍信息那里应该有个搜索按钮，点了就能获取站点信息并选择使用哪些；用户也可以自己复制粘贴图片和填写信息」

## 交付内容

| 能力 | 入口 | 说明 |
|---|---|---|
| 手动改字段 | 详情页字段区 | 书名/系列/卷号/作者可编辑，回车或「保存字段」写入意图账（不动源文件） |
| 粘贴封面 | 详情页「粘贴图片」 | 在别处复制图片 → 窗口内 Ctrl+V → 存本机缓存 |
| 选择封面 | 详情页「选择图片…」 | 桌面壳走原生文件选择器；B/S 模式走文件输入框 |
| 清除封面 | 详情页「清除封面」 | 删缓存文件并回退到文件内嵌封面 |
| 联网搜索 | 详情页「搜索书籍信息…」 | 可编辑查询词 + 勾选数据源 → 候选列表（封面/作者/年份/来源/贴合度）→「用这条」或「只用封面」 |
| 数据源 | Google Books / Open Library / Bangumi | 全部免费、无需 API key；Bangumi 对中文漫画/轻小说最对口 |
| 网络代理 | 设置 → 网络代理 | 跟随系统（默认，读 Windows 代理设置）/ 直连 / 自定义 |

## 安全与隐私（写进设计文档 §8.2）

- 只在点「搜索书籍信息」时联网；扫描/启动/浏览全程零网络
- 只发书名/系列/卷号/作者，不发路径、不发文件、不发指纹
- 域名固定白名单（含封面域名），一律 https；封面下载进本机缓存，不热链
- 候选由用户挑选，写入的是本机意图（override），源文件零改动

## 期间抓到的三个真问题

1. **Go 默认不读 Windows 系统代理**：本机代理软件只写注册表（`Internet Settings`），不设环境变量 → 联网请求全部直连超时。已实现读取注册表并跟随系统代理（非 Windows 平台回退环境变量）。
2. **封面下载用了 `http.DefaultClient`**：绕过了配置好的代理客户端 → 8 个候选封面各超时 12s，一次搜索耗时 96s 且全部拿不到图。改用带代理的客户端 + 并发下载（限 4 并发）后，同样查询 **4.5s、8/8 张封面全部拿到**。
3. **Google Books 免 key 配额按 IP 计**：走共享出口的代理时容易 429。已做成「单源失败不影响其它源」，界面只提示失败源。
