## 1. 任务清单

> 验收列中「单测」指 `go test ./...` 覆盖；「L1」指 300 本合成库集成用例；「手测」指人工清单。

### M0 骨架（可编译、可测）

| 编号 | 任务 | 依赖 | 产出 | 验收 |
|---|---|---|---|---|
| T-01 | 仓库骨架与工程配置：`go.mod`、`cmd/` + `internal/` 目录、Makefile/任务脚本、GitHub Actions（vet + test + build） | — | 可编译骨架 + CI 工作流 | `go build ./...` 与 `go test ./...` 通过；CI 绿 |
| T-02 | 测试数据生成器 `tools/testdata-gen`（分级 l1/l2/l3/l4/edge、固定种子、幂等、**1GB 写入硬上限**） | T-01 | 生成器 + `manifest.json` | 重复运行不重建；超限报错；各档位数据量与预算表一致 |
| T-03 | 领域层：身份与指纹（`blake2b-128(首64KB‖size)`、碰撞降级、移动认领） | T-01 | `internal/domain/identity.go` | 单测：指纹稳定、碰撞降级、认领 |
| T-04 | 领域层：元数据模型与覆盖合并（用户 > 内嵌 > 文件名）+ 系列/卷号解析 | T-01 | `domain/metadata.go`、`domain/series.go` | 单测：优先级、断档识别、命名变体 |
| T-05 | 解析层：CBZ（ComicInfo.xml + 首图 + 页数）、EPUB（OPF）、PDF（基础） | T-02, T-03 | `internal/parse/*` | 单测：用生成器样本，覆盖有/无内嵌元数据、损坏文件 |
| T-06 | 存储层：原子写、镜像（`index.jsonl`/`shelf.json`/`scan_state.json`）、滚动备份、损坏恢复 | T-01 | `internal/store/*` | 单测：半写恢复、备份回退、JSON 损坏回退 |

## 3. 里程碑与 tag 映射

| 里程碑 | 含任务 | 门禁（全绿才打 tag） | tag |
|---|---|---|---|
| M0 骨架 | T-01 ~ T-06 | 单元测试全部 + 生成器自检 + CI 绿 | `v0.1.0-m0` |
| M1 内核 | T-07 ~ T-12 | 单元 + L1 集成 + 边界族 + 覆盖率 ≥ 60%（domain/scan/store） | `v0.1.0-m1` |
| M2 界面 | T-13 ~ T-16 | L1 + 手测清单 + 离线自动化用例 | `v0.1.0-m2` |
| v0.1.0 | T-17 ~ T-18 | L2 性能回归 + L3 发版验收 + 全部 P0 用例 | `v0.1.0` |

**逐里程碑收尾动作序**（固定，不跳步）：本地门禁（vet/build/全量测试）→ 提交推送 → 确认 CI 绿 → 打**附注 tag** 指向已验证 SHA → 档案记录 SHA。

## 4. 砍序规则（范围告急时）

按序砍：T-15 的详情页外链 → T-12 扩展名映射 → T-10 命名混乱清单 → T-16 离线自动化（降为手测）。
**保底不砍**：T-01 ~ T-09、T-11、T-13、T-14、T-17。

## 5. 已知风险与缓解

| 风险 | 缓解 |
|---|---|
| Wails v2 工具链在 Windows 上的初次配置耗时 | T-13 前先做一次最小 demo 验证工具链；失败则退回「纯 Go + 浏览器」（`transport` 抽象已备） |
| 测试数据生成器自身的写入量失控 | T-02 内置硬上限 + manifest 记账 + 幂等复用 |
| 剪枝盲区（原地覆盖写）导致集成用例假绿 | 边界族中固定一个「同 mtime 覆盖」用例，并在 L2 跑一次强制全量校验对比 |
